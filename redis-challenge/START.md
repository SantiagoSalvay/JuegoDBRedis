# 🚀 Inicio Rápido - Redis Challenge

## Para empezar a jugar AHORA:

### 1️⃣ Instalar dependencias (solo la primera vez)
```bash
npm install
```

### 2️⃣ Iniciar el juego
```bash
npm run dev
```

### 3️⃣ Abrir en el navegador
Abre tu navegador en: **http://localhost:5173**

---

## 🎮 ¡A JUGAR!

1. Haz clic en "Comenzar 🚀"
2. Lee cada pregunta cuidadosamente
3. Selecciona tu respuesta
4. Observa el feedback inmediato
5. ¡Intenta conseguir el máximo puntaje!

---

## 🌐 Compartir el juego

Para compartir con tus alumnos:

### Opción A: Proyectar en clase
- Ejecuta `npm run dev` en tu computadora
- Proyecta la pantalla
- Jueguen en modo grupal

### Opción B: Deploy en línea (5 minutos)

1. Sube el código a GitHub
2. Ve a https://vercel.com
3. Importa tu repositorio
4. ¡Deploy automático!
5. Comparte la URL con tus alumnos

---

## ⚡ Comandos útiles

```bash
npm run dev      # Inicia el servidor (desarrollo)
npm run build    # Construye para producción
npm run preview  # Vista previa del build
```

---

## 🎯 Personalizar preguntas

Edita el archivo: `src/data/questions.json`

Formato:
```json
{
  "question": "¿Tu pregunta aquí?",
  "options": ["Opción A", "Opción B", "Opción C", "Opción D"],
  "answer": "Opción correcta"
}
```

---

## 🆘 Problemas?

- **No inicia:** Verifica que Node.js esté instalado (`node --version`)
- **Puerto ocupado:** Vite usará automáticamente otro puerto
- **Estilos raros:** Ejecuta `npm install` de nuevo
